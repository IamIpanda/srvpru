# srvpro

A Rust rewrite of the [srvpro](https://github.com/mycard/srvpro) YGOPro duel server, built on [ygopro](https://crates.io/crates/ygopro).

> This documentation was generated by AI and is still under human review. It may contain
> inaccuracies.

## Usage

```rust,no_run
#[tokio::main]
async fn main() {
    env_logger::init();
    if !srvpro::init().await {
        std::process::exit(1);
    }
    tokio::signal::ctrl_c().await.ok();
}
```

Plugins are registered at link time through `linkme`. Whether a plugin runs is decided by the configuration, so linking a plugin crate is enough to make it available.

## API and persistence

This crate only contains pure game server, don't contains any API or database.

The HTTP API, accounts and the SQLite persistence layer live in the separate
[`srvpro-api`](https://crates.io/crates/srvpro-api) crate. Linking it into the binary enables
them; none of that is part of this crate.
