# srvpro-api

HTTP API and persistence for the [srvpro](https://crates.io/crates/srvpro) duel server.

> This documentation was generated by AI and is still under human review. It may contain
> inaccuracies.

Linking this crate into a `srvpro` binary registers the API plugin. It serves following functions as plugin:

- the room list, player status and duel logs;
- account authentication by password or signed token;
- the configuration endpoint;

Persistence is a SQLite database. More SQL database support may come in future.
